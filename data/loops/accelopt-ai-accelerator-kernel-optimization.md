# AccelOpt: A Self-Improving LLM Agentic System for AI Accelerator Kernel Optimization
**Authors:** Genghan Zhang, Shaowei Zhu, Anjiang Wei, Zhenyu Song, Allen Nie, Zhen Jia, Nandita Vijaykumar, Yida Wang, Kunle Olukotun
**Venue:** ISCA 2026 Architecture 2.0 Workshop (Session 4)

## Abstract & Key Concepts
Optimizing execution kernels for highly parallel deep learning accelerators requires navigating an extremely large search space (tiling sizes, loop unrolling, memory streaming). Human tuning is slow, and black-box mathematical optimizers often fail to leverage architectural intuition.

AccelOpt introduces a self-improving multi-agent framework powered by LLMs. The system operates as a closed loop: generating kernel optimization attempts, evaluating performance metrics on real target hardware, analyzing bottlenecks using trace analysis, and feeding those insights back to update its own optimization strategies autonomously.
