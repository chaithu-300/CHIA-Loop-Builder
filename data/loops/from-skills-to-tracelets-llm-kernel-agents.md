# From Skills to Tracelets: Dependency-Guided Transfer for LLM Kernel Agents
**Authors:** Shuoming Zhang, Ruiyuan Xu, Qiuchu Yu, Guangli Li, Huimin Cui, Jiacheng Zhao
**Venue:** ISCA 2026 Architecture 2.0 Workshop (Session 4)

## Abstract & Key Concepts
Custom GPU and accelerator kernel compilation demands deep domain-specific knowledge of memory layouts, register limits, and hardware execution hierarchies. While coding agents can be trained to optimize kernels on specific baseline tasks, transferring these optimization "skills" to novel microarchitectures is highly challenging.

This work introduces "Tracelets," which are dependency-guided execution abstractions that capture generalized hardware-software optimization patterns. By indexing performance characteristics as localized Tracelets, LLM kernel agents can dynamically adapt learned skills to completely unseen computing hardware.
