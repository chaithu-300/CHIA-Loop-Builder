# HDLxGraph: Bridging Large Language Models and HDL Repositories via HDL Graph Databases
**Authors:** Jiayin Qin, Pingqing Zheng, Fuqi Zhang, Zishen Wan, Shang Wu, Yu Cao, Caiwen Ding, Yang Katie Zhao
**Venue:** ISCA 2026 Architecture 2.0 Workshop (Session 4)

## Abstract & Key Concepts
Hardware Description Language (HDL) repositories represent complex hierarchical relationships that are difficult for standard sequential tokenizers to comprehend. Typical Retrieval-Augmented Generation (RAG) approaches struggle to represent the structural connectivity of modules, wires, and signals.

HDLxGraph addresses this by parsing HDL structures into dedicated graph databases. This allows LLMs to query codebases using graph-structured context, mapping signal paths and architectural dependencies accurately. This significantly improves an agent's capability to modify and debug large-scale digital designs without breaking physical logic chains.
