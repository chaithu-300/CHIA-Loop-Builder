# Fail2Bench: Turning RTL Agent Failures into a Self-Curating Benchmark
**Authors:** Aryan Chhabra, Sumedh Narahari, Shritan Settipalli, Aadarsh Sivaraman
**Venue:** ISCA 2026 Architecture 2.0 Workshop (Session 3)

## Abstract & Key Concepts
As agentic systems are deployed to write and debug hardware RTL code, they inevitably encounter compilation, timing, or logical failures. Traditional benchmarking relies on static human-designed problems, which quickly become saturated as models improve.

Fail2Bench introduces an automated, self-curating benchmark framework that captures real-world failures of active RTL agents in real-time. By systematically cataloging, structuring, and isolating these fail states, Fail2Bench continuously generates high-difficulty benchmark problems that represent the exact boundaries of current LLM reasoning.
