# Benchmarking Agentic HLS Design Tasks With HLS-Eval
**Authors:** Stefan Abi-Karam, Callie Hao
**Venue:** ISCA 2026 Architecture 2.0 Workshop (Session 3)

## Abstract & Key Concepts
High-Level Synthesis (HLS) raises the abstraction level of hardware design, allowing hardware description languages (HDLs) to be compiled from C/C++ specifications. However, compiling code utilizing LLMs for specialized HLS tools introduces distinct evaluation difficulties due to structural tool-specific pragmas and strict hardware optimization goals. 

HLS-Eval establishes a rigorous benchmarking platform specifically constructed to evaluate how modern frontier models and agentic workflows handle C-to-RTL synthesis directives. The paper defines standard criteria for assessing correctness, resource optimization, and overall performance of generated RTL blocks.
